## 🚀 SUBIR A HOSTALIA (Próximo paso)

### Opción A: Subir como carpeta (más fácil)
1. Entra a Hostalia → Gestor de archivos
2. Crea una carpeta `/public_html` (si no existe)
3. Sube TODO el contenido de `web-laurafajardo/` ahí
4. Tu web será: `https://laurafajardo.com`

### Opción B: Subir a WordPress (después)
1. Crea WordPress en Hostalia
2. Instala un tema responsive (Astra, OceanWP)
3. Copia el contenido HTML a las páginas de WordPress
4. Ahí podrás agregar blog, testimonios dinámicos, etc.

## ❓ PREGUNTAS FRECUENTES

### ¿Puedo cambiar el contenido?
**Sí.** Abre `index.html` con un editor de texto (Notepad, VS Code, etc.) y edita lo que quieras.

### ¿Necesito actualizar algo en las redes sociales?
**Sí.** Actualiza los enlaces de LinkedIn e Instagram en el footer (`index.html`).

### ¿Cómo hago que el formulario envíe emails?
Puedes usar servicios gratuitos como:
- **Formspree** (formspree.io)
- **Emailjs** (emailjs.com)
- **Basin** (usebasin.com)

Por ahora, el botón WhatsApp funciona como contacto principal.

### ¿Puedo usar esto sin internet?
**Sí**, puedes abrir `index.html` directamente en tu navegador (sin servidor). El único botón que necesita internet es WhatsApp.
